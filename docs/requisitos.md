
Alcance Mínimo del Proyecto

• Crear un ticket con titulo y descripcion.
• Seleccionar categoria y prioridad.
• Cambiar estado: Nuevo, En proceso, Resuelto y Cerrado.
• Asignar el ticket a una persona.
• Agregar comentarios al ticket.
• Ver listado, buscar y filtrar tickets.
• Consultar el historial de cambios de cada ticket


Tecnologias sugeridas

Backend Python + FastAPI
Base de datos SQLite o PostgreSQL
Frontend HTML/CSS/JavaScript
Entorno Docker
Control de versiones Git
Asistente de desarrollo Open Code
